# Non-Goals

Use this file before committing to the SVG workflow.

## 1. Statistical Charts

### Not a fit

Bar charts, line charts, scatter plots, and similar quantitative graphics.

### Why

This skill is built for topology, routing, and explanatory structure, not chart grammar or axis-based quantitative comparison.

### Use instead

Use a charting-oriented tool or chart grammar workflow.

## 2. Very Large Relationship Graphs

### Not a fit

Hundreds or thousands of nodes in a freeform network.

### Why

The skill assumes a clear reading path and controlled route channels. Large networks break that assumption.

### Use instead

Use graph exploration or network visualization tooling.

## 3. Brand Illustration Or Poster Art

### Not a fit

Decorative hero art, campaign posters, or purely visual storytelling without structural explanation.

### Why

This skill optimizes for semantic readability, not illustration craft or brand expression.

### Use instead

Use a design or image-generation workflow.

## 4. High-Fidelity UI Mockups

### Not a fit

Product screens, polished web pages, and interface design comps.

### Why

The skill focuses on diagrams and explanatory systems, not interface layout or component design systems.

### Use instead

Use a UI or product design skill.

## 5. Dense Dashboards

### Not a fit

Multi-panel dashboards packed with KPIs, charts, and filters.

### Why

The diagram workflow depends on one dominant explanation path. Dense dashboards require a different information architecture.

### Use instead

Use a dashboard or product analytics design workflow.
