# MacBook Pro 14″ Teardown — Production Brief

> 示例产物：用 3d-brief skill 按"全默认"走完流程生成的 brief（MacBook Pro 14″ 拆解爆炸图）。研究事实来自 Apple 官方规格页与 iFixit 拆解报告。

> 一句话叙事主线：精密如同产品本身——部件沿拆解轴线安静分层展开，Space Black 阳极氧化铝在克制的轮廓光下呈现工业之美。

## 00 / RUNTIME — Implementation Environment

- Compute: 当前机器（macOS, Apple Silicon）· Cycles GPU 走 Metal
- DCC: Blender CLI 4.2 LTS；无 MCP、无插件，纯 Blender Python 驱动
- Harness: ZCode agent CLI — 评审循环要求子代理（新鲜上下文评审员）
- Starting Assets: 无，全部从零生成
- Budget · Autonomy: 单次会话内完成 · ≥3 轮评审循环 · 完全自主，零人工干预

## 01 / TASK — 角色、自主权、完成定义

你是本项目的首席概念设计师、硬件结构与装配逻辑顾问、产品材质专家、灯光渲染艺术家与最终质量负责人。在当前工作目录完成实际工作；不要只交付计划、教程或示例代码。

用户可能不在场：做保守、可逆的假设，记录它们，继续。不要为非阻塞的美学选择、可选下载或缺失的便利插件停下来。只在三种情况停：凭据、潜在破坏性外部操作、不 materially 改变授权范围就无法解决的根本性歧义。

持续工作到本简报的显式质量门被满足为止——而不是到第一个能跑的文件或第一张好看的渲染图出现为止。

## 02 / PROTOCOL — 可恢复性

动手前先探查环境：当前目录、Blender 版本与可执行文件、可用渲染引擎与设备、已装插件、已有资产。可选插件与下载不得成为阻塞点，提供原生替代。使用隔离的 `macbook_teardown/` 目录。

## 03 / BUILD ORDER — 构建顺序

1. **美术圣经与规划集**：把简报转成美术圣经、爆炸分层规划（拆解顺序→轴向层级）、资产清单、材质语言、固定相机集、技术预算、验收地图。
2. **可渲染灰盒**：整机与全部部件的比例块灰盒，爆炸轴向就位，5 个固定相机全部架好。用真实尺寸（312.6 × 221.2 × 15.5 mm 为基准）。
3. **立即预览评审集**：立刻渲染低成本预览（低采样），暴露比例、分层、构图、相机失败。
4. **资产族替换**：以连贯的资产族替换占位体——先宏观剪影（整机轮廓、部件体块），再功能结构（接口、排线走向、散热鳍片），最后近距细节（螺丝、丝印、屏蔽罩、倒角）。每轮替换后保持全场景可渲染。
5. **最终陈设与灯光**：材质分离、灯光层级、相机构图。高采样与昂贵效果只留给确认的最终 5 视角。

## 04 / REVIEW LOOP — 证据驱动评审

固定评审集 = 07 节第 8 小节的最终相机清单（5 机位）。至少 3 轮完整循环：

**构建/修改 → 渲染固定评审集 → 检视真实像素与 contact sheet → 诊断 → 修复 → 同机位重渲**

批评只认渲染出来的图像——不认代码、场景树、视口描述或构建者总结。每条发现记录：相机/文件证据、严重度、受影响子系统、可能根因、可执行修正。影响多帧的系统性问题先于孤立抛光。

评审员（新鲜上下文子代理，输入 = 完整 07 节 + 该轮全分辨率原始渲染 + 评分表，由构建者原样转发不得增删；评分输出逐维度数值分 + 扣分证据，当轮维度分取各评审员最低分；每轮归档 `renders/round_<n>/` 与 `reviews/round_<n>/`）：

1. **硬件结构评审员**：部件清单完整性、装配关系、爆炸轴向是否符合真实拆解顺序（对照 iFixit 拆解：底盖 → 电池连接断开 → 扬声器/风扇 → 逻辑板 → 屏幕总成）
2. **材质表面评审员**：阳极氧化铝、PCB、玻璃、金属膜的 PBR 可信度与一致性
3. **爆炸构图评审员**：部件分层可读性、视觉层级、hero 视角的信息密度
4. **灯光渲染评审员**：曝光、反射控制、噪点、景深使用是否正当
5. **Blender 技术评审员**：场景组织、命名、实例化、路径、可移植性

**回归纪律**：每轮修复后将同一相机与上一版对比，标注 improved / unchanged / regressed。材质回退必须修复或回滚。每轮完整循环后更新 contact sheet、TASK_STATE.md 与评分证据。

**停滞升级**：连续两轮完整循环总分提升不足 1 分时，强制做结构改造——重新审视爆炸分层逻辑、部件比例体系、灯光架构、hero 构图，而不是继续堆小道具、表面噪波或装饰光。

## 07 / BRIEF — 领域内容

### 1. 目标与叙事

作品集英雄图：一张能证明"硬表面建模 + 产品材质 + 爆炸构图"三项能力的正视图。观看介质为桌面大屏。成功标准：业内人士一眼认出这是 MacBook Pro 14 的可信拆解，而非泛泛的"笔记本电脑爆炸图"。

**Avoid 清单（走捷径即失败）**：廉价光晕与泛光；过浅景深掩盖部件细节；塑料感材质；爆炸轴向混乱；游戏化炫彩灯光；部件悬浮角度随机无逻辑。

### 2. 主体规格与范围

研究事实（标注来源）：

- 机型：MacBook Pro 14″（M4, 2024），颜色取 **Space Black**
- 整机尺寸：**312.6 × 221.2 × 15.5 mm**，重 1.55 kg（来源：Apple 官方技术规格页）
- 逻辑板较上代重新设计，**散热器更大**；电池结构与上代相同（来源：iFixit M4 Pro 拆解报告）
- 双风扇布局延续上代（推断）；接口子板与天线模块位置（推断，参照公开拆解图）

范围：T2 主板级拆解——外壳组 + 内部主要模组 + 主要排线，不含每颗螺丝的独立建模（螺丝类实例化处理）。

### 3. 资产族与最低内容

- **主体模组 ≥12**：底盖、顶壳（含键盘）、屏幕总成（含玻璃）、逻辑板（M4 机型接口大多集成于板：左 2×Thunderbolt + MagSafe、右 Thunderbolt + HDMI + SD；音频孔独立小板 ×1——推断，参照公开拆解图）、电池组（多软包电芯 + 框架，分芯可见——teardown 最有辨识度的细节之一）、扬声器 ×2、风扇 ×2、散热模组、触控板
- **细节资产 ≥15**：排线 ×6、芯片屏蔽罩 ×3、散热鳍片组、天线模块、螺丝类实例 ≥40 颗位（规格 ≥2 种）、连接器端子 ×8
- 重复部件（螺丝、排线、扬声器）实例化，但朝向、位置状态必须有变化，不许复制粘贴阵列感

每个重要资产必须在三个阅读距离上成立：远看可识别剪影、中看功能结构、近看接缝/丝印/倒角/螺丝规格。贴纹理的薄盒子不是可见功能结构的可接受替代。

### 4. 结构与建造细节

- 爆炸几何细则：部件沿整机厚度方向（Z 轴）分层展开，hero 相机主轴指向镜头并带约 15° 仰角——避免纯正交堆叠在正视图中大面积互相遮挡。层序表（下→上）：底盖 → 电池组 → 扬声器 ×2 + 风扇 ×2（同层横向错开）→ 散热模组 → 逻辑板（含屏蔽罩与集成接口）→ 排线带（跨相邻层的弧形连接）→ 顶壳（键盘 + 触控板）→ 屏幕总成；层间距面到面 ≥15 mm；同层部件允许 XY 错位 ≤30 mm 与 ≤3° 微旋换取分层可读性；爆炸总高目标 180–220 mm，hero 取景框中整机占比约 70%。灰盒阶段产出俯视分层布局图存入 ART_DIRECTION.md
- 螺丝区分规格（底盖 pentalobe 与内部 torx 的视觉暗示：头槽形状不同）
- 排线有连接器端子与走向弧度，不允许是直的平面带
- 所有制造边缘有符合尺度的倒角（铝件 0.3–0.8 mm 视觉暗示）

### 5. 材质与表面语言

- Space Black 阳极氧化铝（**喷砂 bead-blasted** 表面工艺，非拉丝——MacBook unibody 工艺）：base #1a1a1c–#2a2a2e，roughness 0.3–0.45，细微各向异性仅用于塑高光形态，不做可见拉丝纹理
- 逻辑板 PCB：深墨–黑绿底、芯片丝印、metallic 局部
- 电池组：银灰金属膜 + 黑色标签贴片
- 屏幕总成：低铁玻璃（正面）、内侧消光黑边框
- 散热模组：纯铜色（metallic 1.0, roughness 0.3）与石墨灰
- 扬声器网罩：细密冲孔暗示

物理可信的 Principled BSDF；禁止：默认灰材质、拉伸 UV、Z-fighting、悬浮穿插、不合理 razor-sharp 边缘。

### 6. 环境与灯光

暗背景轮廓光英雄感：

- 主轮廓光：5500K 侧逆光 ×2（左右各一，强度不对称制造层次）
- 顶部柔光 fill：大面积低强度，保证顶部曲面有渐变
- 背景：深灰渐变 #0d0d0f → #1a1a1e
- 色彩管理：AgX；保护高光细节与暗部可读（部件边缘在暗背景中仍可辨）
- 反射内容：为高金属度件（铜散热模组 metallic 1.0）提供大面积渐变"灯箱"World 或反光板——纯金属在近零环境下会渲染成发闷色块
- 不使用 practical 光源；不用 HDRI 环境

### 7. 叙事痕迹

不适用——崭新无痕的档案式拆解美学（默认档位）。唯一允许的"动感"：悬浮分层的静态凝固感本身。

### 9. 技术组织与可移植性

命名 Collections：`chassis` / `internals` / `cabling` / `fasteners` / `lighting` / `cameras`。描述性英文命名，不许 Cube.001 式命名泛滥。螺丝与重复件实例化。外部文件走相对路径或打包进 .blend。交付的 .blend 保持可编辑——保留修改器、实例、集合结构。

### 10. 致命视觉失败清单

以下任一出现即不可接受：

- 整机或部件比例明显偏离 312.6 × 221.2 × 15.5 mm 基准
- 部件数低于第 3 小节清单的 80%
- 爆炸分层轴向混乱、部件交叉重叠无拆解逻辑
- 材质呈塑料感或存在默认灰材质
- 只有 hero 角度能看，特写与反向角度细节崩塌
- 用黑背景、光晕或景深掩盖未完成或缺失的部件
- renders/final/ 缺失、含视口截图或不含最终场景
- 最终 .blend 无法在干净环境打开并渲染
