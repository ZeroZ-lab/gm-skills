# 只问影响结果的缺口

这不是必答问卷。已知信息跳过；用户“全推荐/你定”后沿用推荐，不换一种说法再问。每次只呈现当前可决定的关键缺口，附推荐和影响；客观规格、工具是否安装由 Agent 自查。

| 缺口 | 何时需要问 | 可采用的默认 |
|---|---|---|
| 主体 | 连对象都未确定 | 无，先明确对象 |
| 用途 | 作品集、科普、产品页会改变成果 | 未指定时静态展示，记录假设 |
| 真实型号 | 多个型号结构不同 | 不混用；查候选后问确切型号 |
| 创意方向 | 参考不足且未授权自主决定 | 提出少量有区别的方向并推荐 |
| 拆解深度 | 内部结构会显著扩张范围 | 外观级；明确拆解请求则列主要模组方案 |
| 环境规模 | 容量、区域影响范围 | 提议小型完整空间，不擅加后厨或露台 |
| 制作预算 | 已授权执行但无资源上限 | 先提明确上限；只写简报时记为执行前待配置 |

普通细节由 Agent 决定：按用途选择相机数、焦距、采样与材质参数；相机必须证明清单覆盖，而不是固定凑 5 张。确定性制造部件保持正确对称与排列，仅在合理位置引入变化。适用的预算与授权已在上下文提供时直接使用。
