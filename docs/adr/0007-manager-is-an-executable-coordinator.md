# Manager is an executable coordinator

The Manager may execute Codex Plugin, Claude Code Plugin, and `npx skills` native operations on the Operator's behalf. It must first derive the intended Runtime, Package Format, scope, affected Capabilities, and expected registry changes; destructive or broad actions require confirmation. For each target Runtime independently, it prefers that Runtime's native Plugin format when the Remote Source provides it and falls back to `npx skills` only when the native format is unavailable. If neither Native Installer supports the target Runtime, or its executable is unavailable, the mutation Action is blocked; list and doctor may still derive state from readable native records. The Manager must not copy files, create links, or edit private state to emulate support. After execution it rereads the authoritative native records and regenerates Unified Inventory. The Manager never implements installation mutations itself and never treats its Unified Inventory as a registry.
