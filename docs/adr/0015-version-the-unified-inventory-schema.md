# Version the Unified Inventory schema

Unified Inventory is an explicit versioned contract for Installation Packages, Package Formats, Installations, Capabilities, Exposures, Observed Evidence, and Identity Resolution. The next Observed Evidence deepening changes the contract to schema `2.0`: evidence gains Evidence Subject, Evidence Validity, Evidence Provenance, and Evidence Findings; invalid or runtime-detection evidence no longer manufactures installation entities. The command entrypoint `python3 scripts/inventory.py --json` remains stable. Because the Manager stores no inventory history and schema `1.0` has no supported mutation consumer, implementation replaces `1.0` rather than maintaining two output shapes; fixtures, skill instructions, and validators move atomically with the schema version.
