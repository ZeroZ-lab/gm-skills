# Preview Package Impact before installation

Before installing an Installation Package, the Manager reports its Package Impact: Capabilities, hooks, MCP servers, commands, scripts, apps, authentication requirements, Package Formats, Remote Source, Revision, package root, target Runtime, and scope. A package containing executable extensions beyond Skills requires additional explicit confirmation even when the original request named the package. The Manager reports verifiable contents and provenance but does not claim to certify remote code as safe.
