# Test the versioned inventory through synthetic fixtures

Stage 1 behavior tests use Inventory Fixtures containing synthetic Runtime Facts, temporary files, and Native Installer outputs for Codex Plugin, Claude Code Plugin, `npx skills`, and unmanaged ZCode detection. Fixtures cover valid and invalid Observed Evidence, cross-format Capability convergence, differing and unknown Revisions, Unresolved Identity, managed and unmanaged Exposures, scope overlap, and Duplicate Exposure. The public inventory entrypoint and versioned Unified Inventory JSON are the primary test surface; direct Runtime Adapter tests are limited to acquisition and parsing edge cases, private normalization helpers are not a contract, and the real machine is used only for read-only smoke testing.
