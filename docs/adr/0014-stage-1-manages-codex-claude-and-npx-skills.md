# Stage 1 manages Codex, Claude Code, and npx skills

Stage 1 supports Codex Plugin and Claude Code Plugin as managed Runtime formats and `npx skills` as the standalone Native Installer. ZCode may be detected and reported as an unmanaged Runtime, but the Manager does not install, uninstall, enable, disable, or infer authoritative state from ZCode private cache and data paths. A future ZCode adapter requires a stable Native Installer plus Registry and Discovery Verification evidence.
