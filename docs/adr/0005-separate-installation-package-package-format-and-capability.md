# Separate Installation Package, Package Format, and Capability

The Manager models three distinct concepts. An Installation Package is a remote package identified by Remote Source plus package root directory. Multiple runtime manifests inside that same directory belong to one Installation Package; manifests in different directories identify different packages even when they reference the same Capability. A Package Format is the package's runtime-specific representation: `codex-plugin`, `claude-code-plugin`, `npx-skills`, or `built-in`. A Capability is an individual callable skill identified by Remote Source plus canonical `SKILL.md` path. Codex and Claude Code plugin formats remain operationally separate, but can belong to the same Installation Package and expose the same Capabilities. Inventory shows both package and capability views; package-level removal must report every affected Capability.
